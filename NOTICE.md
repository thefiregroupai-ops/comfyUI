# Third-party names and components

This repository contains workflow definitions that reference third-party software, models, custom nodes, and services. Those components are not bundled and retain their own licenses, acceptable-use policies, and distribution terms.

Names such as ComfyUI, Flux, Ideogram, Krea, MiniMax, Qwen, SeedVR2, and Wan are used only to describe workflow compatibility. FIRE Group AI Ops is not affiliated with or endorsed by those projects unless explicitly stated by the relevant owner.

Before downloading a model or installing a custom node, review its source, license, security posture, and hardware requirements. A workflow JSON can describe third-party code but cannot grant rights that the component owner has not granted.

The repository itself does not currently include a repository-wide license. See the license-status section in the root README.
