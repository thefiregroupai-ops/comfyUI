# LoRA Dataset Tools

This folder contains a ComfyUI workflow for preparing character image datasets with grounding, segmentation, and prompt-driven processing.

## Workflows

| Workflow | Summary | JSON | Details |
| --- | --- | --- | --- |
| AI Influencer Character LoRA Dataset AIO v1.1 | Generates segmented character dataset images and mask previews using SAM3 grounding and Qwen text encoding. | [FIRE_INFLUENCER_Dataset_AIO_v1.1.json](./FIRE_INFLUENCER_Dataset_AIO_v1.1.json) | [View workflow details](https://thefiregroupai-ops.github.io/comfyUI/workflows/lora-dataset-tools/influencer-dataset-aio/) |

## Quick start

1. Download the workflow JSON from the table above.
2. Launch ComfyUI and load the JSON file onto the canvas.
3. Resolve any missing models or nodes shown by the workflow, then queue it. See [How to Install and Load a ComfyUI Workflow JSON File](https://thefiregroupai-ops.github.io/comfyUI/guides/how-to-install-comfyui-workflow-json/) for the site's import guidance.
