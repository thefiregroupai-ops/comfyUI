📂 Krea2 ComfyUI Workflows

Compare four Krea2 workflow JSONs for identity editing, depth-guided control, before-and-after comparison, and multi-reference generation.

Choose Krea2 by the constraint you need to preserve

Use Identity Edit v1.2 when you have both a source-person image and a target-scene image. Its two grounded encoders, identity-edit LoRA, resizing stages, and image comparer are arranged around restaging identity. Use the Multi-Reference Selector when several views describe the subject better: the saved graph exposes four image slots, primary and secondary selectors, prompt lists, and a face-detailing branch.

Choose a depth workflow when structure matters more than exact identity. ControlNet Depth Anything v3 derives a depth representation from the supplied image, previews that representation, and applies Krea2 depth control before sampling. Depth Control & Image Compare is the more compact A/B route, with the loaded source and generated result feeding an image comparer.

Do not treat identity and depth as interchangeable controls: a depth map can guide silhouette and spatial layout without defining a person. Import only one JSON for the first test, replace every example image, check the active selectors, and verify all Krea2, VAE, text-encoder, LoRA, detector, or depth loaders present in that specific graph. Compare the first output against the input constraint you chose before adjusting prompts or adding more references.
