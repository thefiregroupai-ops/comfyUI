Krea2 ControlNet Depth Anything v3 Workflow

Depth-guided image generation and structural pose control using Krea2 UNet and Depth Anything V3 preprocessor.

⬇️ Download Workflow JSON ⭐ View Source on GitHub

🛠️ Technical Specifications

  • Model Family: Krea2 Turbo FP8, Depth Anything V3
  • Primary Tasks: controlnet-depth
  • Node Count: 22 nodes
  • Key ComfyUI Nodes Used: Krea2ControlApply, DepthAnything_V3, UNETLoader, KSampler
  • Required Custom Node Packs: ComfyUI-Krea2, DepthAnythingV3
  • Availability: Public direct download

📥 Inputs & Outputs

  • Inputs: Pose / Structural Reference Image, Text Prompt
  • Outputs: Depth Map Preview, Conditioned Final Image

Best Uses for Depth-Guided Krea2 Generation

This 22-node graph is intended for edits where the source image should control scene geometry more strongly than color or texture. One LoadImage node feeds Depth Anything V3, which exposes depth, confidence, resized-image, camera, and mask outputs. The selected depth is encoded to the latent size and applied to the Krea2 model through Krea2ControlImageEncode and Krea2ControlApply. Text conditioning then describes what should appear inside that retained structure.

That makes the workflow a practical fit for pose retention, composition restaging, and other cases where silhouettes and foreground-to-background spacing matter. The final decode reaches both a preview and SaveImage, so the graph has a persistent output path as well as visual feedback. Inspect the Krea2 ControlNet workflow JSON, or compare other edit approaches on the Krea2 workflow family page.

Depth Preview and Model Checks Before Running

Replace the bundled image, then verify that the Depth Anything model, Krea2 UNET, CLIP, VAE, and depth-control LoRA resolve on your installation. The graph includes non-core Krea control nodes, FearNWorks Depth Anything nodes, and the custom-scripts text display. If ComfyUI shows them in red, install the matching extension and restart before troubleshooting the prompt or sampler.

Depth guidance follows the map produced from the input, so an incorrect structural interpretation will also steer the generated image incorrectly. Inspect the depth-related output before relying on the final render, especially when the source contains overlapping subjects or ambiguous edges. The control encoder is set to match the latent size and convert the control image to grayscale; changing image dimensions without checking that path can change the structure being supplied. The Krea2 identity and depth guide explains how this family of controls fits into a larger edit process.

📖 How to Import & Run in ComfyUI

  1. Click Download Workflow JSON above to save FIRE_KERA_2_CONTROLNET_WORKFLOW_1.json to your computer.
  2. Launch ComfyUI in your web browser.
  3. Drag and drop the downloaded JSON file directly onto the ComfyUI canvas.
  4. If red missing nodes appear, open ComfyUI-Manager -> click Install Missing Custom Nodes -> Restart ComfyUI.
  5. Ensure model weights for Krea2 Turbo FP8, Depth Anything V3 are located in your models/ folder.
  6. Click Queue Prompt.
