Ideogram Director v10 LLM Refiner Workflow

Prompt director and resolution setup pipeline integrated with Local LLM prompt refinement for Ideogram.

⬇️ Download Workflow JSON ⭐ View Source on GitHub

🛠️ Technical Specifications

  • Model Family: Ideogram, Local LLM
  • Primary Tasks: prompt-engineering
  • Node Count: 14 nodes
  • Key ComfyUI Nodes Used: DenoIdeogramDirector, DenoLocalLLMRefiner, DenoResolutionSetup
  • Required Custom Node Packs: Deno Custom Nodes
  • Availability: Public direct download

📥 Inputs & Outputs

  • Inputs: Raw Text Prompt, Resolution Preset
  • Outputs: Refined prompt data and a generated image preview; add a SaveImage node for persistent files

Plan, Generate, and Preview with Ideogram Director

Ideogram Director v10 contains 14 top-level nodes in two prompt-input groups. Its DenoIdeogramDirector node turns a backdrop and optional imported JSON into a prompt, width, height, seed, and bounding-box data. The prompt, dimensions, and seed feed an embedded Text to Image (Ideogram v4) subgraph, whose image output reaches PreviewImage. The sampler, model-loader, and VAE logic are encapsulated inside that subgraph rather than exposed on the outer canvas.

This layout supports composition planning and a generated preview in the same workflow, while the second group provides a local-LLM-assisted prompt-refinement path for comparison. The top-level graph does not include a SaveImage node, so add one after the embedded generator if you need persistent output. Open the Ideogram Director JSON source to review the two groups, or compare other options on the Ideogram and Flux workflow family.

Local LLM Setup and Output Handoff

The optional refinement route uses DenoLocalLLMRefiner and is stored with local-provider settings, including a loopback URL at http://127.0.0.1:8000/v1. The JSON does not start an LLM server or install a model for you. Choose the provider and model that are actually available on your computer, update the endpoint if necessary, and test that service independently before queueing the graph. The Deno nodes are custom nodes, so ComfyUI must recognize them after import.

Once the prompt, dimensions, seed, and boxes look correct, run the embedded Ideogram v4 generator and inspect its preview. Because the outer graph has no SaveImage node, connect an explicit save step to the generated image when you need a downloadable file. Keep the generated layout JSON with the output if you want the composition to be reproducible later. The workflow import and missing-node guide covers the initial drag-and-drop and extension checks.

📖 How to Import & Run in ComfyUI

  1. Click Download Workflow JSON above to save FIRE_ideogramDirector_v10.json to your computer.
  2. Launch ComfyUI in your web browser.
  3. Drag and drop the downloaded JSON file directly onto the ComfyUI canvas.
  4. If red missing nodes appear, open ComfyUI-Manager -> click Install Missing Custom Nodes -> Restart ComfyUI.
  5. Ensure model weights for Ideogram, Local LLM are located in your models/ folder.
  6. Click Queue Prompt.
