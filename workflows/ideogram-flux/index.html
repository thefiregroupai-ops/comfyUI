📂 Ideogram & Flux 2 Klein ComfyUI Workflows

Compare three downloadable ComfyUI JSON workflows for Flux 2 Klein generation, Ideogram reference conditioning, and local prompt refinement.

Which Ideogram or Flux workflow should you start with?

Choose by input type. The Flux 2 Klein FP8 Text-to-Image workflow starts from text, dimensions, and a noise seed. Its graph includes a prompt list, so it is the direct choice when you want to run several written concepts rather than preserve a supplied subject. Review one prompt first, then use sequential prompt execution after the model, VAE, dimensions, and save path are working.

The Ideogram 4 + LoRA Single Reference workflow adds a reference image to the decision. Its saved graph uses an Ideogram scheduler, dual model guidance, CFG control, and LoRA loading. Use it when a particular reference should condition the result; judge identity and composition before changing several guidance controls at once.

The Ideogram Director v10 workflow is the prompt-preparation option. It accepts a raw prompt and resolution preset, then uses its Director, local-LLM refiner, and resolution nodes to produce refined text and an image. Choose it only when you intend to configure the local-LLM portion of that graph. For any of the three, open the detail page, import the linked JSON, replace example inputs, resolve every loader and custom node, and run a single controlled test before combining prompt batches or reference conditioning.
