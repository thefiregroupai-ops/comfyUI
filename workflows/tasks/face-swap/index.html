How to test the Qwen face-swap workflow safely

The workflow currently listed here is Qwen Faceswap & Batch Folder v1. It takes a face reference and either one body image or images loaded from a directory. The saved graph has labeled switches for single-image and folder modes, an optional orientation path, face-analysis and bounding-box stages, face detailing, image comparison, and upscaling. Use those controls rather than rewiring the graph for the first run.

Begin in single-image mode. Choose a clear reference with visible facial landmarks and a target where the intended head is unambiguous. Replace both example inputs, resolve every Qwen, VAE, LoRA, face-analysis, detector, and upscaler loader, then inspect the detected face region and pre-upscale result. Check jaw and hair boundaries, head angle, skin tone, and lighting—not only the eyes and mouth. If the angle is incompatible, test the labeled orientation branch while leaving the other settings fixed.

Move to folder mode only after one target succeeds. Point the directory loader at two known files, verify ordering and output names, and then expand the batch. An upscaler can enlarge an edge or geometry error; it does not prove the replacement is correct. Use images you have permission to edit, obtain consent when an identifiable person is involved, and disclose synthetic alteration wherever the result could reasonably mislead a viewer.
