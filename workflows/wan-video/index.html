📂 Wan Video ComfyUI Workflows

Compare two Wan video workflow JSONs for overlap-frame video extension and audio-conditioned talking-head generation.

Choose Wan by how the longer video is assembled

The Wan 2.2 I2V Infinite Extender starts from one image and builds connected video sections. Its saved graph exposes animation length, frame rate, frame split, and overlap, with image-batch extension branches for a linear blend and a cut. Choose it for continued motion from a visual starting point, then compare the two seam treatments on a short test before requesting a longer result.

The Wan 2.1 Podcast Basic 34s workflow has a different input contract: one speaker image plus uploaded audio. It repeats InfiniteTalk conditioning, sampling, decoding, batching, and video-combine stages, with labeled duration bypass controls and a final saving note. Choose it for the listed single-speaker talking-head use case, not as a generic replacement for the extender.

Both JSON files retain example media and loader choices. After import, resolve missing custom nodes separately from missing model files, replace every image or audio input, and confirm which output node is active. Match the graph’s dimensions or orientation to the source, use simple motion or speech material for the first queue, and inspect the first segment before activating more duration. If an extender seam jumps, isolate overlap and branch choice; if a podcast output ends early, inspect the active duration chain.
