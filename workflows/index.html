How to choose a ComfyUI workflow category

Start with the output you need, then choose the family whose inputs match the material you already have. Ideogram & Flux covers prompt-led image generation, single-reference conditioning, and prompt refinement. Krea2 focuses on identity edits, multi-reference characters, and depth-guided structure. Qwen contains image restaging, face replacement, skin refinement, and a ControlNet graph. If the image is already approved and only needs a larger or more detailed finish, begin with Upscalers & Tools instead of regenerating it.

For motion, compare the input contract before comparing model names. MiniMax-H3 offers first-and-last-frame control, automatic aspect handling, and a larger cinema graph with reference and audio controls. Wan Video provides an overlapping image-to-video extender and a multi-section podcast workflow driven by an image and audio. The LoRA Dataset Tools category is for preparing character material, not for producing the same kind of final image as an editing workflow.

You can also browse by outcome: character consistency, depth control, image-to-video, or upscaling. Open a workflow’s detail page before downloading its JSON. The detail page identifies its expected inputs and outputs; the JSON then supplies the saved graph, not the external models, custom nodes, or example media it references.
