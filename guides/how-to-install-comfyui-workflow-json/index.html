How to Install & Load a ComfyUI Workflow JSON File

Step-by-step guide on importing JSON workflows into ComfyUI, using ComfyUI-Manager to install missing custom nodes, and loading model weights.

A ComfyUI workflow JSON is loaded, not installed. Drag the downloaded .json file onto the ComfyUI canvas (or use ComfyUI’s workflow-open control), then supply the custom nodes, model files, and input media referenced by that graph. The JSON stores the node layout, connections, and widget values; it does not bundle those dependencies.

Before you import the workflow

  1. Save or export the graph currently on your canvas if you may need it again.
  2. Download the JSON directly rather than copying the text displayed by a browser. A valid download should be a file ending in .json, not an HTML page renamed as JSON.
  3. Open the matching workflow detail page and note its stated inputs, outputs, node packs, and model family. Start at the FIRE ComfyUI workflow library if you have not chosen a graph yet.

You can practice with a smaller image workflow such as Krea2 Identity Edit (JSON download) or Qwen Classic Img2Img (JSON download). Video graphs such as the Wan I2V Extender (JSON download) have more inputs and are better attempted after the import process is familiar.

Load the JSON and read the canvas

  1. Launch ComfyUI and wait for the canvas to finish loading.
  2. Drag the JSON file from your file manager onto the canvas. The saved graph should appear with its groups, links, notes, switches, loaders, and output nodes.
  3. Zoom out and scan from inputs to outputs before queuing. Read any notes embedded in the workflow; several FIRE video graphs include model, resolution, duration, or saving instructions directly on the canvas.
  4. Look for red, unknown, or disconnected nodes. Do not delete them just to make the warning disappear: that node may perform a required part of the workflow.

Install missing custom nodes

If ComfyUI-Manager is already available, open it and use Install Missing Custom Nodes to scan the imported graph. Review the proposed packages, install the ones that correspond to the workflow, restart ComfyUI, and load the JSON again. A restart matters because newly installed Python and web components are not necessarily available to the running session.

Manager can match many node types, but it cannot guarantee that every unfamiliar node name maps to one current package. If a node remains missing, use the workflow detail page and the node’s exact type or label to identify the dependency. Review a custom-node repository and its installation instructions before running its installer; custom nodes execute code in your ComfyUI environment.

Resolve models and replace example inputs

Next, inspect every checkpoint, UNet, CLIP, VAE, LoRA, ControlNet, upscaler, vision, and detector loader present in the graph. A loader with an unavailable filename will not be fixed by installing a node pack. Select a compatible file already installed in the loader’s expected model category, or follow the model references included on the workflow canvas or detail page. Do not rename an unrelated model merely to match the saved widget value.

Replace all example images, audio uploads, video files, and folder paths. JSON files commonly preserve the creator’s local filename or path, but the referenced media is separate from the graph. For a batch loader, first point it to a tiny test folder whose contents you know. Check labeled switches and bypass controls too: a valid input on an inactive branch will still be ignored.

Run a safe first test

  1. Confirm that the intended save or preview node is connected and enabled.
  2. Use a short duration or modest dimensions when the workflow exposes those controls.
  3. Queue once and read the first error in the console or interface. Later errors are often consequences of that first failure.
  4. After a successful output, change one input or setting at a time and save your working copy under a new name.

Common import problems

  • The JSON opens as text or fails to parse: download the raw JSON again and confirm the file was not an error page or repository web page.
  • Nodes stay red after installation: restart ComfyUI, reload the original graph, and check whether the missing node pack reported an installation error.
  • A model name is red or blank: the node exists but its referenced model does not. Resolve that loader separately from custom-node installation.
  • The graph runs with the wrong media: replace saved example inputs and verify the active switch, folder path, and batch ordering.
  • No file appears: follow the links from the final decode or batch node to the active save/video-combine node and check its filename prefix and save toggle.
