Best ComfyUI Workflows for Character Consistency & AI Influencers

Master facial and body consistency across multiple images using Krea2, Qwen Faceswap, and LoRA dataset generation pipelines.

The most reliable way to keep a character consistent is to choose the workflow by the thing that must stay fixed. Use Krea2 Identity Edit when a known person must be restaged into a target image, the Krea2 multi-reference graph when several photos should guide one character, Qwen Faceswap when a reference face must be applied to one image or a folder, and the dataset workflow when you first need a reusable set of character views. These are different jobs, so there is no single “consistency” control that replaces good references and careful review.

Choose the right character-consistency workflow

Krea2 Identity Edit: identity plus a target scene

The Krea2 Identity Edit v1.2 workflow page describes a two-image graph: one source-person photo and one target-scene photo. Its JSON includes two LoadImage nodes, grounded positive and negative encoders, the identity-edit LoRA, resizing stages, and an image comparer. Choose this route when the desired composition already exists and the identity is the part you want to change. Download the Identity Edit JSON.

Krea2 multi-reference: several views of one subject

The Krea2 Multi-Reference Selector workflow exposes four reference-image slots and two four-way image switches in the graph. It also includes a face-detailing stage, a SAM loader, prompt lists, and before/after comparison. This makes it the better starting point when one portrait does not adequately describe the subject’s face and body. Use photos of the same person, select the intended primary and secondary references in the switches, and confirm that the chosen images are feeding the active branch before queuing. Download the Multi-Reference JSON.

Qwen Faceswap: single images or a body-image folder

The Qwen Faceswap & Batch Folder workflow contains separate single-image and folder-selection controls, plus face bounding-box, orientation, face-detailing, and upscaling nodes. Use its labeled switches rather than rewiring the graph: select the single-image path for a test, or the batch path only after the test output is acceptable. The prompt already instructs the edit stage to match lighting, skin tone, face shape, and placement while retaining the rest of the body image. Download the Qwen Faceswap JSON.

A repeatable setup and review process

  1. Download one workflow and drag its JSON onto the ComfyUI canvas. Work from the dedicated detail page above so the expected inputs and output are clear.
  2. Resolve missing custom nodes before changing the graph. Red or unknown nodes mean the imported workflow cannot run as saved.
  3. Replace every example image or folder path. Start with one sharp, unobstructed reference and one target. For multi-reference work, add only images of the same subject.
  4. Run a small controlled test. Keep the references and prompt fixed while you confirm that the active switches, loaders, and save nodes are correct.
  5. Review face shape, eye spacing, hairline, skin tone, body proportions, pose, hands, clothing edges, and background continuity. A convincing face alone does not make a consistent character.
  6. Change one variable at a time and compare outputs. The included comparer nodes in the Krea2 and Qwen graphs are useful for separating an actual improvement from seed-to-seed variation.

Build a dataset before you need one

If your source material is weak or covers only one angle, inspect the AI Influencer Character Dataset AIO workflow. The graph includes a prompt list, SAM3 grounding for face and hair, mask previews, face detailing, stitched previews, and image comparers. Treat it as a dataset-preparation pipeline: inspect segmentation and identity in every output rather than assuming a generated batch is automatically training-ready. Download the Dataset AIO JSON.

Troubleshooting identity drift

  • The wrong image is being edited: check the labeled image switches and folder selector; imported graphs retain example paths and switch positions.
  • The face is plausible but not the same person: simplify the requested scene, use a clearer reference, and test a second angle through the multi-reference graph.
  • Edges or lighting look pasted on: compare the face crop with the target’s head angle and illumination; use the orientation branch in the Qwen graph where appropriate.
  • A workflow stops at a red node: install the missing node package, restart ComfyUI, reload the JSON, and confirm that each model loader resolves an installed file.
  • A batch silently uses the wrong files: test a folder containing only two known images, verify ordering and output names, then point the loader at the full set.
