MiniMax H3 ComfyUI Guide — Setup, Models & Free Workflows

Compare MiniMax H3 workflows for first and last frame control, automatic aspect ratios, cinema controls, and audio reference inputs.

Start with the MiniMax-H3 workflow whose controls match your source material. Use First & Last Frame when both endpoints matter, Auto-Aspect FP8 when one image should determine the output shape, and Top Cinema when you need the collection’s broader reference, audio, resolution, model-selection, and frame-interpolation controls. Importing the biggest graph first usually makes setup harder to diagnose.

Choose a MiniMax-H3 workflow

First & Last Frame: control both endpoints

The MiniMax-H3 First & Last Frame workflow contains two image loaders, image-to-video conditioning, duration and resolution controls, video and audio VAE decoding, and an H.264 video-combine output. Use it when the animation should begin from one supplied frame and arrive at another. The graph scales both images before conditioning, so choose endpoint images with compatible framing and aspect ratio; a drastic change in subject scale or camera angle gives the transition more work to resolve. Download the First & Last Frame JSON.

V3 Auto-Aspect FP8: preserve one image’s shape

The MiniMax-H3 V3 Auto-Aspect FP8 workflow loads one source image, resizes it by total pixel area while retaining its aspect ratio, reads the resulting dimensions, and passes them into the image-to-video stage. Its embedded note says the resized dimensions are aligned to a multiple of 32. This makes it a focused starting point for portrait, square, or landscape sources without manually entering width and height. Download the Auto-Aspect JSON.

Top Cinema: references, audio, interpolation, and manual controls

The MiniMax-H3 Top Cinema workflow is the most configurable of the three. The saved graph includes image and video reference inputs, an audio loader, reference-to-video and image-to-video conditioning paths, manual width and height, model and conditioning switches, a duration control, and RIFE frame interpolation with a target-FPS control. It also contains notes about prompt structure, model links, custom nodes, and connecting reference-video audio. Read those canvas notes before enabling optional groups. Download the Top Cinema JSON.

Set up MiniMax-H3 in ComfyUI

  1. Download one workflow JSON and drag it onto the ComfyUI canvas.
  2. Resolve missing custom nodes, restart ComfyUI, and load the graph again. These workflows use MiniMax-H3 conditioning plus video-combine and utility nodes; First & Last Frame uses KJNodes-style model loading, while Top Cinema adds interpolation and rgthree controls.
  3. Inspect the graph’s diffusion-model or UNet, CLIP, video VAE, audio VAE, and optional LoRA loaders. Use the filenames and model notes saved in that specific graph as the dependency checklist; do not assume the three workflows select identical model variants.
  4. Replace all example images, video references, and audio. A workflow JSON stores their prior filenames but not the source files themselves.
  5. For the first run, keep the saved sampler wiring intact and use a short duration. Confirm that decoding and video saving work before changing optional branches or interpolation.
  6. Save a working copy under a new filename before experimenting with model, conditioning, or group-bypass switches.

Prepare frames and write motion prompts

Use a clean source frame whose subject and background are easy to read. For endpoint control, make the first and last frames feel like two moments from the same shot: similar crop, consistent identity, and a plausible path between poses. If you intentionally want a scene change, test that change separately before combining it with complex character motion.

Describe visible events in sequence: the subject’s action, camera movement, environmental motion, and the desired final state. In reference-to-video work, follow the subject and picture notation documented in the Top Cinema prompt note. Keep the first prompt compact. Once the graph produces a valid clip, add timing and shot details one at a time so you can see which instruction changes the result.

Troubleshooting MiniMax-H3

  • The graph imports with unknown nodes: install the missing package, restart, and reload the original JSON. Do not replace a specialized conditioning node with a similarly named generic node.
  • A loader cannot find its saved file: the custom node is present but the model dependency is not resolved. Check the loader category and the graph’s embedded model note.
  • First and last frames jump: reduce differences in crop, aspect ratio, subject size, and background, then retest with simpler motion.
  • Auto-aspect output is unexpected: inspect the resized preview and reported dimensions before sampling; confirm the source image itself was not pre-stretched.
  • Top Cinema uses the wrong path: inspect the labeled model, conditioning, latent, resolution, and optional-function switches rather than rewiring downstream nodes.
  • Interpolation changes playback but not generation: remember that RIFE operates after generated frames; diagnose content and continuity before enabling the interpolated output.
