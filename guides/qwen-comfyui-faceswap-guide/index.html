Qwen ComfyUI Face Swap & AI Skin Realism Guide

Learn how to use Qwen Image Edit Plus and SeedVR2 DiT for batch folder face swapping and photorealistic micro-pore skin texture enhancement.

Use the Qwen Faceswap graph to establish identity and placement first, then use the Real Skin workflow as a separate refinement pass only if the portrait needs it. Combining face replacement, batch processing, detail recovery, and final upscaling before one clean test makes it difficult to see where an artifact entered the pipeline.

What the Qwen Faceswap workflow does

The Qwen Faceswap & Batch Folder workflow accepts a face reference and either a single body image or images loaded from a directory. Its labeled controls distinguish single-image mode, batch-folder mode, and an optional face-orientation path. The graph includes Qwen image-edit text encoding, face analysis and bounding boxes, image resizing, face detailing, comparison views, and two upscaling stages. Download the Qwen Faceswap JSON.

The saved edit instruction asks the model to fit the new face to the body image by matching lighting, skin tone, face shape, and placement while keeping the rest unchanged. Treat that as the workflow’s core job. First prove it on one target image; only then point the directory loader at a batch.

Prepare the reference and target images

  • Face reference: choose a sharp image with visible facial landmarks and limited occlusion. A neutral or compatible head angle gives the first test fewer conflicts.
  • Target body image: make sure the face is large enough to inspect and that the intended head is unambiguous. Multiple faces can make detection and selection harder.
  • Angle and lighting: if reference and target differ strongly, use the graph’s labeled orientation option and review the intermediate preview rather than assuming the final upscaler will correct geometry.
  • Usage rights: edit only images you are allowed to use, obtain consent where a real person is identifiable, and label synthetic or altered media when the context could mislead viewers.

Run a single face swap before a batch

  1. Drag the downloaded JSON onto the ComfyUI canvas, resolve missing custom nodes, restart ComfyUI, and reload the graph.
  2. Check every UNet, CLIP, VAE, LoRA, face-analysis, detector, and upscaler loader. Select files actually present in their expected model categories.
  3. Replace both example images and choose the labeled single-image path. Leave the folder path inactive for this test.
  4. Queue once and inspect the face crop, placement, pre-upscale result, and comparer. Check jaw and hair edges as well as eyes, nose, and mouth.
  5. If the head angle is incompatible, test the orientation branch with the same images. Do not change prompt, reference, and upscaling settings at the same time.
  6. After one target works, create a small folder with two known images, select batch mode, set its directory path, and verify ordering and output names before processing a larger set.

Use AI Real Skin v5 as a finishing workflow

The AI Real Skin v5 workflow is a separate portrait-processing graph, not a switch inside Faceswap. Its canvas is organized into base upscale, heavy refinement, and final SeedVR2 upscale sections. Exposed controls include detail level, smoothness or softness, face-mask blur, and upscale multiplier, with multiple comparison and save nodes. Download the AI Real Skin v5 JSON.

Feed it an already-approved face-swap output and begin from the saved settings. Compare the base, heavy-refinement, and final outputs at the same zoom. Skin detail should support the portrait, not erase identity cues or introduce a different face. If mask boundaries are visible, inspect the face-mask blur control; if facial structure changes, return to the earlier stage instead of trying to repair it with more upscaling.

Related Qwen image-editing options

For restaging without the batch face-swap controls, see Qwen Classic Img2Img and its workflow JSON. For a graph with Qwen Image Edit Plus encoding and single-image or directory loading, see Qwen Image Unleashed v2 and its workflow JSON. These are alternative editing graphs; do not assume their model loaders or node dependencies match Faceswap.

Troubleshooting face and skin artifacts

  • The wrong face is detected: test a target with one clear face and inspect the bounding-box stage before face detailing.
  • The face looks pasted on: use a closer angle match, inspect the orientation branch, and compare lighting and skin tone before upscaling.
  • Batch mode processes unexpected files: test with a two-image folder and confirm the directory loader’s ordering before expanding the batch.
  • Identity changes after refinement: compare the base, heavy, and final Real Skin outputs to identify the first stage where drift appears, then reduce or bypass that stage.
  • A loader is blank or red: distinguish a missing custom node from a missing model file; they require separate fixes.
