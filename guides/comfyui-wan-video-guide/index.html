Wan 2.1 & 2.2 Image-to-Video ComfyUI Workflow Guide

Master Wan 2.1 and Wan 2.2 Image-to-Video generation in ComfyUI, including infinite video extension, overlap frames, and talking head setups.

Choose the Wan workflow by output structure, not simply by the model number. The Wan 2.2 extender turns a start image into repeated, overlapping video sections; the Wan 2.1 podcast graph pairs a speaker image with audio and assembles multiple talking-head sections. Both are image-to-video workflows, but their inputs, timing controls, and failure modes are different.

Which Wan workflow should you use?

Wan 2.2 I2V Infinite Extender

Use the Wan 2.2 I2V Infinite Extender workflow when you have one starting image and want to build a longer animation from connected sections. The saved graph includes a start-image loader, positive and negative text conditioning, CLIP vision encoding, two sampling stages, and image-batch extension nodes. Its visible controls include animation length, frame rate, frame split, and overlap. One branch uses a linear blend at the overlap and another uses a cut, so inspect which output branch is connected to the video-combine node you intend to save. Download the Wan 2.2 Extender JSON.

Wan 2.1 Podcast Basic 34s

Use the Wan 2.1 Podcast Basic 34s workflow for a single-speaker image and an uploaded audio file. The graph repeats WanInfiniteTalkToVideo, sampler, decode, batch, and video-combine stages, then joins the sections. It provides width and height controls, a duration selector made from labeled bypass controls, and a final save note inside the canvas. This is a large, purpose-built graph; first test its shortest active duration path before attempting the complete sequence. Download the Wan 2.1 Podcast JSON.

Import and run a Wan image-to-video graph

  1. Download the JSON from the relevant workflow page and drag it onto an open ComfyUI canvas.
  2. Resolve every missing-node warning, restart ComfyUI, and reload the JSON. The extender uses video-helper, image-resize, math, and rgthree-style utility nodes; the podcast graph also relies on its InfiniteTalk and audio-processing nodes.
  3. Check each model, CLIP, VAE, vision, patch, and LoRA loader already present in the graph. Select files that exist in the corresponding ComfyUI model folders; an installed custom node does not supply a missing model file.
  4. Replace the example start or speaker image. For the podcast graph, also replace the example audio upload. Set width and height to the same orientation as the source image rather than stretching a portrait into landscape or the reverse.
  5. Write motion instructions that describe observable action, camera behavior, and scene continuity. Keep the first test simple so you can tell whether a problem comes from conditioning, timing, or the graph setup.
  6. Queue a short test and inspect the preview or first saved section. Only then increase animation length, activate more podcast sections, or change the overlap.

How to improve continuity between sections

Start from an image with a clear subject, stable lighting, and enough room for the requested movement. In the extender, the overlap is the handoff between generated sections: too little shared material can reveal a jump, while a blend can still show double edges if the subject changes position sharply. Compare the cut and blend branches already present in the graph. Keep the prompt consistent across the test, change only one timing control, and watch the seam frame by frame before producing a longer result.

For the podcast workflow, crop and size the speaker image before the long run, then verify that mouth area, head position, and framing remain usable in the first section. Listen to the source audio for silence, clipping, or an incorrect file before blaming the video stage. The graph includes multiple intermediate video-combine nodes; identify the final active node and follow the embedded saving note so you do not mistake an intermediate segment for the assembled output.

Troubleshooting Wan video workflows

  • Nothing queues: look for red nodes and unresolved loader selections. Fix the first reported dependency, restart, and reload before diagnosing downstream nodes.
  • The output has the wrong shape: confirm the loaded image’s aspect ratio and the graph’s width, height, or resize controls. Do not judge motion from a visibly stretched input.
  • A seam flashes or duplicates the subject: shorten the test, compare the cut and linear-blend outputs, and adjust overlap while leaving the prompt and seed unchanged.
  • The podcast output ends early: inspect the labeled duration bypass controls and make sure the intended chain of repeated sections is active.
  • The final file has no expected audio: confirm the upload node contains the intended file and that you are saving from the final video-combine node, not an intermediate preview.
  • Generation runs out of memory: stop the queue, reduce the active duration or image dimensions for diagnosis, close other GPU work, and retest before restoring the full settings.
