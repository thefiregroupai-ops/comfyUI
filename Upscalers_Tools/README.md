# Upscalers and Tools

This folder contains ComfyUI workflows for SeedVR2-based image upscaling, megapixel scaling, and film-grain enhancement.

## Workflows

| Workflow | Summary | JSON | Details |
| --- | --- | --- | --- |
| Ideogram 4 + SeedVR2 Film Grain Upscaling | Combines megapixel scaling, SeedVR2 upscaling, cache cleanup, and film-grain enhancement. | [FIRE_Ideogram_4_Additional_Upscaling_Workflow_1.json](./FIRE_Ideogram_4_Additional_Upscaling_Workflow_1.json) | [View workflow details](https://thefiregroupai-ops.github.io/comfyUI/workflows/upscalers-tools/ideogram-4-additional-upscaling/) |
| SeedVR2 High-Resolution AI Upscaler | Upscales input images with a SeedVR2 DiT pipeline and sharpening control. | [FIRE_Upscaler.json](./FIRE_Upscaler.json) | [View workflow details](https://thefiregroupai-ops.github.io/comfyUI/workflows/upscalers-tools/fire-upscaler/) |

## Quick start

1. Download a workflow JSON from the table above.
2. Launch ComfyUI and load the JSON file onto the canvas.
3. Resolve any missing models or nodes shown by the workflow, then queue it. See [How to Install and Load a ComfyUI Workflow JSON File](https://thefiregroupai-ops.github.io/comfyUI/guides/how-to-install-comfyui-workflow-json/) for the site's import guidance.
