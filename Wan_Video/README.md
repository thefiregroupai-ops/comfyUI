# Wan Video Workflows

This folder contains ComfyUI workflows for Wan image-to-video generation, including video extension and a multi-batch podcast pipeline.

## Workflows

| Workflow | Summary | JSON | Details |
| --- | --- | --- | --- |
| Wan 2.2 I2V Infinite Video Extender v1 | Extends image-to-video output with frame overlap controls for continued animation. | [FIRE_I2V_Infinite_extender_v1.json](./FIRE_I2V_Infinite_extender_v1.json) | [View workflow details](https://thefiregroupai-ops.github.io/comfyUI/workflows/wan-video/i2v-infinite-extender/) |
| Wan 2.1 Podcast Basic 34s Image-to-Video | Generates a multi-batch talking-head or podcast video from a speaker image and audio input. | [FIRE_PodcastBasic_img_to_vid_34s.json](./FIRE_PodcastBasic_img_to_vid_34s.json) | [View workflow details](https://thefiregroupai-ops.github.io/comfyUI/workflows/wan-video/podcast-basic-img-to-vid-34s/) |

## Quick start

1. Download a workflow JSON from the table above.
2. Launch ComfyUI and load the JSON file onto the canvas.
3. Resolve any missing models or nodes shown by the workflow, then queue it. See [How to Install and Load a ComfyUI Workflow JSON File](https://thefiregroupai-ops.github.io/comfyUI/guides/how-to-install-comfyui-workflow-json/) for the site's import guidance.
